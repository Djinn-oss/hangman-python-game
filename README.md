# 🎮 Hangman Game (Python)

A classic console-based **Hangman** game built with Python. This project demonstrates core programming fundamentals, including loops, conditional logic, list manipulation, and string formatting.

---

## 📌 Features

* **Input Validation:** Ensures the user enters only one character at a time.
* **Duplicate Detection:** Prevents losing a turn if a letter has already been guessed.
* **Case Insensitivity:** Automatically handles uppercase and lowercase letter inputs (`.lower()`).
* **Visual Progress Tracking:** Dynamically updates hidden words using underscores (`_`) alongside guessed characters.

---

## 🛠 Technologies Used

* **Language:** Python 3.x
* **Standard Library:** `random`
